## Source automatisée des offres gratuites — recherche

- [GamerPower API](https://www.gamerpower.com/api-read) documente les filtres Steam et Epic et les offres actives; ses [conditions API](https://www.gamerpower.com/api-read) permettent l’usage commercial avec attribution/hyperlien, interdisent de revendiquer ou revendre les données. Ses [règles de curation](https://www.gamerpower.com/guidelines) demandent des offres gratuites, largement disponibles dans la plupart des pays, de plus de 1 000 clés, effectivement en cours et sans paywall/points. C’est une source candidate autorisée, mais « la plupart des pays » ne prouve pas l’accès depuis la France.
- La page API annonce du JSON structuré et les filtres plateforme/type, mais ne spécifie pas les propriétés. Un GET réel du 19 octobre depuis le PC fixe confirme le champ `open_giveaway_url` avec des liens `www.gamerpower.com/open/...`; l'API renvoie aussi HTTP 201 et `{"status":0,"status_message":"No active giveaways available at the moment, please try again later."}` lorsqu'aucune offre n'est active. Un exemple Steam avait `status: "Active"`, `end_date: "N/A"`, sans champ de région, et une autre offre exigeait des points. Le code valide ces deux formes observées, borne les candidats, refuse les URL hors de gamerpower.com, bloque les redirections de l’API, suit un seul redirect manuel pour `/open/` et n’accepte que des fiches produit officielles Steam/Epic. Aucun contournement TLS n’est utilisé. Le filtrage réduit les offres non admissibles mais le prix réellement gratuit et la région FR restent non vérifiés.
- L’[API IsThereAnyDeal](https://docs.isthereanydeal.com/) publie un endpoint de giveaways avec `expiry`, mais requiert une clé API et son exemple public ne fournit pas de région; l’[information pour boutiques](https://isthereanydeal.com/contact/stores/) dit que l’accès API est lié au partenariat des boutiques. Ce n’est pas à ce stade une source générale plus directement exploitable.
- Epic expose ses offres sur sa [page officielle Free Games](https://store.epicgames.com/FREE-GAMES?lang=en-US), sans flux public documenté identifié dans sa documentation développeur. Steam décrit les promotions Free-to-Keep dans sa [documentation Steamworks](https://partner.steamgames.com/doc/marketing/discounts/freetokeep?language=english); la documentation ne fournit pas un flux public global permettant d’assurer prix/région/expiration des giveaways.
- Conclusion : GamerPower est permis sous attribution et le GET Node fonctionne sur le PC fixe. Le flux in-app est implémenté derrière deux réglages OFF par défaut, les offres manuelles restent prioritaires et les doublons de produit sont retirés (Steam par AppID).
