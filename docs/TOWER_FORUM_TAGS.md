# Forums The Tower — proposition de tags (sans création)

Les tags de forums sont un outil de découverte, pas des rôles de permissions. Les tags ci-dessous sont **proposés**, non vérifiés sur le serveur et non créés.

| Forum | Tags (5 maximum initiaux pour éviter la dispersion) |
| --- | --- |
| Recherche de joueurs | PC, PlayStation, Xbox, Switch, Cross-play |
| Recrutement d'équipe | Débutants bienvenus, Détente, Compétitif, Long terme, Recherche capitaine |
| Projets / aventures | Coop, Construction, Exploration, Survival, Événement |

Champs conseillés dans le modèle de publication : **jeu**, plateforme, disponibilités/heures Paris, micro oui/non, taille de groupe et style de partie. Conserver la possibilité d'écrire « jeu gratuit / navigateur » pour l'accessibilité.

## Contrôle avant configuration
- Lire les tags déjà présents et conserver ceux utilisés par les publications existantes.
- Vérifier qu'aucun tag ne contient d'information personnelle ni de promesse d'accès réservé.
- Tester dans la guild sandbox sur un compte non modérateur.
- Les changements des forums réels nécessitent un accord ; aucune modification par cette PR.
